# Paste Base64 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make File → Paste Base64 load a pasted JKS or BCFKS keystore, automatically detecting the container and asking only when needed.

**Architecture:** Add a testable background task that decodes text with `Base64Decoder` and probes JKS and BCFKS through `KeyStoreLoader`. `MainShellController` owns JavaFX dialogs and submits the task using the existing status/progress wiring; it never logs or persists input.

**Tech Stack:** Java 17, JavaFX, Maven, JUnit 5, AssertJ, existing keystore-core fixtures.

## Global Constraints

- Keep Base64, decoded bytes, passwords, and key material out of logs, settings, errors, and reports.
- Decode in memory only; do not create temporary plaintext files.
- Run loading work through the existing background executor, never the JavaFX Application Thread.
- Run `./mvnw verify` before declaring the change complete.
