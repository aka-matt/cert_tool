# Cert Tool

An offline JavaFX desktop tool for reading, parsing, inspecting, and converting **JKS** and **BCFKS** keystores in binary or Base64 form, with a static FIPS 140-2/140-3 compatibility assessment engine.

> **Status: Phase 0 (Repository scaffolding).** Source code lands in Phases 1–7. See `cert_tool.md` for the full specification and `docs/adr/` for architecture decisions.

## Features (target, v1)

- Read JKS and BCFKS in **Binary** and **Base64** forms (file, paste, drag-and-drop, recent files).
- Inspect every entry: alias, type, certificate chain, validity, fingerprint, key algorithm and size, extensions, warnings.
- Run a static **FIPS compatibility assessment** against built-in profiles (`FIPS_140_2_LEGACY_ASSESSMENT`, `FIPS_140_3_ASSESSMENT`) or a user-imported custom profile.
- Convert between any of the four forms with **atomic write** and **reload verification**.
- Export single cert (PEM/DER), full chain (PEM), and assessment reports (JSON/HTML/Markdown). Private-key export is **disabled** by default and not implemented in v1.
- Light / Dark / System themes (AtlantaFX).
- **Fully offline.** No KeyStore, certificate, password, key material, or analysis result is ever uploaded.

## Build

Requires **JDK 17** (Temurin recommended) and network access on the first build to fetch dependencies. The Maven Wrapper (`./mvnw`) pins Maven 3.9.9.

```bash
./mvnw verify         # full build, all quality gates
./mvnw test           # unit tests only
./mvnw compile        # compile only
```

## Run

Once Phases 1–7 are complete:

```bash
./mvnw -pl app -am package
java -jar app/target/cert-tool-app-0.1.0-SNAPSHOT.jar
```

## Supported formats

| Container | Encoding  | Read | Write |
|-----------|-----------|------|-------|
| JKS       | Binary    | ✓    | ✓     |
| JKS       | Base64    | ✓    | ✓     |
| BCFKS     | Binary    | ✓    | ✓     |
| BCFKS     | Base64    | ✓    | ✓     |

## Security notice

- **Offline only.** The application makes no network calls. Do not paste production KeyStores into a network-connected machine running this tool if that violates your environment policy.
- **FIPS disclaimer.** The assessment is a *static compatibility review* against a profile. It is **not** a FIPS certification and does **not** constitute a statement by NIST, CMVP, an accredited lab, or an auditor. See `SECURITY.md` and `FIPS-ASSESSMENT-LIMITATIONS.md` (forthcoming).
- **Private-key export** is disabled by default. v1 does not implement plaintext private-key export.
- **Settings file** stores no secrets. Passwords are never persisted.

## Known limitations (v1)

- Static (offline) assessment only — no CRL fetch, no OCSP, no AIA chasing.
- "FIPS Mode" requires manually placing the Bouncy Castle FIPS Provider jar on the classpath; it is **not** shipped by default because of its commercial license.
- jpackage native installers are out of scope for v1.
